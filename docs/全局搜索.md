# 全局搜索

## 入口

顶栏搜索框：

```text
搜索 Agent / 知识库 / 用例 / 工具
```

## 行为

- 输入至少 2 个字符，250ms 防抖；
- 调用统一后端接口 `GET /api/v1/search?q=`；
- 后端复用 Agent/知识库/用例/工具现有权限查询，不新增旁路；
- 按名称精确/前缀/包含、描述包含做轻量相关度排序，同分按 Agent→知识库→用例→工具排序；最多 20 条；
- 分组展示；
- Agent 点击进入编辑页，知识库进入详情，用例/工具进入列表；
- 权限沿用各模块现有列表权限，不新增旁路；
- 已做真实 UI 冒烟：搜索“客服”命中 Agent 并跳转。
