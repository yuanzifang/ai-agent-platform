# 全局搜索

## 入口

顶栏搜索框：

```text
搜索 Agent / 知识库 / 用例 / 工具
```

## 行为

- 输入至少 2 个字符，250ms 防抖；
- 并行调用现有租户 API：
  - `/agent?keyword=`
  - `/knowledge-base?keyword=`
  - `/cases?keyword=`
  - `/tools?keyword=`
- 分组展示，最多 20 条；
- Agent 点击进入编辑页，知识库进入详情，用例/工具进入列表；
- 权限沿用各模块现有列表权限，不新增旁路；
- 已做真实 UI 冒烟：搜索“客服”命中 Agent 并跳转。
