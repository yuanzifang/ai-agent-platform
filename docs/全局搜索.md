# 全局搜索

## 入口

顶栏搜索框：

```text
搜索 Agent / 知识库 / 用例 / 工具
```

## 行为

- 输入至少 2 个字符，250ms 防抖；
- 调用统一后端接口 `GET /api/v1/search?q=`；
- 后端复用 Agent/知识库/用例/工具现有权限查询，不新增旁路；
- 使用 Jieba SEARCH 模式做中文分词，返回 `tokens` 供排查；名称精确/前缀/包含优先，其次描述，多词覆盖率加分；Agent/知识库/用例/工具支持跨模块权重（默认 1.10/1.05/1.00/0.95，可用 `search.weights.*` 调整）；同分按类型排序；最多 20 条；
- 返回 `nameHtml` / `descHtml`：原文本先 HTML 转义，再用 `<mark>` 标记命中词；前端只渲染后端生成的安全高亮；
- 无结果时从权限内实体名称做轻量编辑距离纠错，返回 `suggestion`，前端展示“你是不是想搜”并支持一键重搜；
- 点击结果时调用 `POST /api/v1/search/feedback`，Redis 按租户/类型/结果 ID 记录 30 天点击次数；后续搜索对有点击记录的结果加分，Redis 故障时静默降级；
- 分组展示；
- Agent 点击进入编辑页，知识库进入详情，用例/工具进入列表；
- 权限沿用各模块现有列表权限，不新增旁路；
- 已做真实 UI 冒烟：搜索“客服”命中 Agent 并跳转。
