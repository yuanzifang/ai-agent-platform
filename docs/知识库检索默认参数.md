# 知识库检索默认参数

更新：2026-10-28

知识库编辑页新增/已有的检索默认参数：

- `defaultTopK` / `maxTopK`
- `defaultRetrievalMode`：`hybrid` / `vector` / `keyword`
- `defaultScoreThreshold`：0–1
- `defaultKeywordWeight`：0–1，仅 hybrid 使用

## 优先级

Agent 绑定知识库时的 `retrievalConfig` 优先；未配置的字段回退知识库默认值：

```text
Agent binding retrievalConfig
  > 知识库默认参数
  > 系统兜底（topK=5, threshold=0.5, hybrid, keywordWeight=0.35）
```

主对话、调试/评测，以及技能/子 Agent 的 RAG 共用同一套默认参数。

## API

知识库创建/更新请求新增：

```json
{
  "defaultRetrievalMode": "hybrid",
  "defaultScoreThreshold": 0.5,
  "defaultKeywordWeight": 0.35
}
```

知识库详情返回同名字段。数据库迁移：`V108__knowledge_retrieval_defaults.sql`。
