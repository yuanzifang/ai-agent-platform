## Prompt 注入检测

- 新增 `PromptInjectionModerationProvider`，接入现有 IN/OUT 审核链：
  - IN 指令覆盖（ignore previous / 忽略之前指令）、系统提示词泄露、安全策略绕过、角色劫持/jailbreak
