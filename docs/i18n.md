# i18n 基础层

## 已实现

- 接入 `vue-i18n` 10；
- `zh-CN` / `en-US` 语言包；
- locale 持久化到 `localStorage.locale`；
- 主框架/登录页语言选择器；
- Element Plus locale 跟随切换（分页/日期/空状态等）；
- document.title / html lang 跟随；
- 已翻译：
  - 应用标题
  - 侧边导航菜单
  - 顶部通知/用户菜单/安全设置/退出
  - 登录页主要字段、登录/SSO/忘记密码/MFA 按钮
  - 邀请激活主要文案
  - 全部一级业务页面标题（Agent 广场/模板/审批/审计/计费/用例/评测/知识库/MCP/记忆/监控/可观测/平台/Provider/技能/系统设置/租户/工具/用量/成员）
  - Agent 编辑页标题

## 未完成

- 业务页面标题已英文覆盖；表单字段、按钮、校验提示、工作流画布仍以中文硬编码为主；
- 后端校验/错误消息、邮件/通知模板未国际化；
- 没有翻译完整性检查/CI 校验；
- 没有日期、数字、货币的 locale 格式化迁移；
- 默认中文 UI 冒烟 4/4；完整 API E2E 37/37；本批次未做英文全页面逐项验收。

## 使用

顶部语言下拉切换 `中文 / English`，刷新后保持；默认中文，避免破坏现有 UI 测试。
