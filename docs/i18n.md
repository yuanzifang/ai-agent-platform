# i18n 基础层

## 已实现

- 接入 `vue-i18n` 10；
- `zh-CN` / `en-US` 语言包；
- locale 持久化到 `localStorage.locale`；
- 主框架语言选择器；
- 已翻译：
  - 应用标题
  - 侧边导航菜单
  - 顶部通知/用户菜单/安全设置/退出
  - 登录页主要字段、登录/SSO/忘记密码/MFA 按钮
  - 邀请激活主要文案

## 未完成

- 全站业务页面（Agent、知识库、评测、计费、审计、MCP、工作流画布等）仍以中文硬编码为主；
- 后端校验/错误消息、邮件/通知模板未国际化；
- 没有翻译完整性检查/CI 校验；
- 没有日期、数字、货币的 locale 格式化迁移；
- 仅验证默认中文下 E2E **29/29** 与基础语言层编译/构建，未做英文全页面验收。

## 使用

顶部语言下拉切换 `中文 / English`，刷新后保持；默认中文，避免破坏现有 UI 测试。
