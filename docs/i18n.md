# i18n 基础层

## 已实现

- 接入 `vue-i18n` 10；
- `zh-CN` / `en-US` 语言包；
- locale 持久化到 `localStorage.locale`；
- 主框架/登录页语言选择器；
- Element Plus locale 跟随切换（分页/日期/空状态等）；
- document.title / html lang 跟随；
- 已翻译：
  - 应用标题
  - 侧边导航菜单
  - 顶部通知/用户菜单/安全设置/退出
  - 登录页主要字段、登录/SSO/忘记密码/MFA 按钮
  - 邀请激活主要文案
  - 全部一级业务页面标题（Agent 广场/模板/审批/审计/计费/用例/评测/知识库/MCP/记忆/监控/可观测/平台/Provider/技能/系统设置/租户/工具/用量/成员）
  - Agent 编辑页标题
  - Agent 列表：工具栏、空状态、卡片状态/操作、新建弹窗
  - 知识库列表：搜索/可见范围、空状态、卡片操作、新建/编辑弹窗
  - 人工审批页：状态、表格、审批弹窗、运行详情、提示消息
  - 模板库：搜索、卡片、预览弹窗、使用模板
  - Agent 广场：筛选、卡片指标、详情、举报处理、评价/回复
  - Prompt 模板：列表、变量、创建/编辑、AI 优化弹窗、引用删除提示
  - 工具管理：列表、API 工具表单、参数 Schema、鉴权、测试、版本、引用删除
  - 技能管理：列表、脚本编辑器、参数/依赖、脚本测试、验证、版本、引用删除
  - 审计日志：Tab、表格、哈希链校验结果
  - 用量看板：周期、指标卡、趋势、按模型、调用明细
  - 长期记忆：画像、列表、自动/范围、增删改、提示消息
  - 成员管理：成员/邀请列表、角色调整、邀请弹窗
  - 租户设置：基本信息、配额、所有者转让、SSO、租户配置
  - 模型接入：Provider/模型列表、接入/密钥、模型配置
  - 计费管理：概览、规则、账单、充值、配额、账单明细

## 使用

顶部语言下拉切换 `中文 / English`，刷新后保持；默认中文，避免破坏现有 UI 测试。
