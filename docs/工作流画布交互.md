# 工作流画布交互（Dify 风格）

画布在 `Agent 编辑 → 工作流 / 人工审批 → 画布布局`。这一版补齐了拖拽建流程最常用的交互，仍复用原有执行引擎（`next` / `edges` / 条件分支 / 并行 / 循环 / 审批），不改变后端协议。

## 交互

| 能力 | 用法 |
| --- | --- |
| 节点面板拖入 | 左侧「节点面板」拖动节点类型到画布任意位置；单击则自动找空位（优先 3 列可视区） |
| 右侧节点配置 | 单击节点即在右侧面板直接改字段；「列表编辑」可看全部高级字段 |
| 端口连线 | 普通节点从右侧圆点拖到目标节点，直接更新 `next`；条件节点用 T/F 端口分别更新 `trueNext`/`falseNext` |
| 改接连线 | 选中显式边 → 工具栏「改接」→ 点击新的目标节点；Esc 或点空白取消 |
| 连线标签 | 条件分支显示 true（绿）/ false（红）；两个分支指向同一节点时合并为 true/false（橙） |
| 撤销 / 重做 | 工具栏 ↶ / ↷，或 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`（输入框内不拦截） |
| 适应画布 | 「适应画布」按内容自动缩放 |
| 运行态高亮 | 运行测试后节点按 `nodeRuns` 状态高亮：成功绿、失败红、运行中蓝、等待/跳过橙 |
| 运行轨迹回放 | 运行结果下方「回放」：按执行顺序逐节点高亮（蓝色脉冲）并显示状态/耗时/输出，支持暂停、上一步、下一步、停止；自动切到画布并滚动到对应节点 |
| 节点删除 | 配置面板右上角「删除」直接删节点（带撤销） |
| 多选 / 批量拖动 | Shift+点击节点多选（橙色边框），拖动任一选中节点会**整体移动**；工具栏「删除所选」或 Delete 批量删除 |
| 框选 | Shift+拖拽空白处画框，框内节点加入多选；框选期间不触发画布平移 |
| 多选限制 | 开始/结束节点不能批量删除；普通点击会清空多选 |
| 复制 / 粘贴 | 工具栏「复制」「粘贴」或 `Cmd/Ctrl+C`、`Cmd/Ctrl+V`；粘贴出的节点自动偏移并选中 |
| 复制规则 | 开始/结束节点不可复制；副本之间的边和 `next/trueNext/falseNext/branches` 引用自动重映射；指向副本外部的 `next` 收敛到 end，避免粘贴出意外连线 |
| 布局持久化 | 节点 `position` 随工作流定义保存，下次打开保持位置 |

## 连线规则（重要）

- **画布连线更新语义**：普通节点拖线直接更新 `next`，条件节点 T/F 端口分别更新 `trueNext`/`falseNext`，避免“画了线但执行不生效”。
- **显式边保留兼容**：下方 Graph 边面板仍可编辑显式边；保存/运行时后端归一化到节点跳转。
- **推导边只读**：节点顺序、条件 true/false、并行分支会自动画线；普通节点只有一条出边。
- **条件分支**：条件节点右侧 T/F 两个端口，不用猜标签。
- **重复保护**：同一节点/分支重复连接会清理旧边，不产生双线。
- **测试用草稿**：运行测试会先保存当前草稿，并以 `draft=true` 执行；正式对话才使用已发布版本。

## 测试与调试

- 运行测试前自动保存草稿，测试不会跑旧的已发布版本。
- 后端 `POST /agent/{id}/workflow/run` 支持 `{ input, draft: true }`；正式调用不传 `draft` 时仍使用发布版本。

## 实现位置

- 画布与交互：`frontend/src/views/AgentEditView.vue`（`wfEdges` / `insertWorkflowNode` / `startLinkDrag` / `connectNodes` / 撤销重做 / `wfRunClass` / 右侧面板）
- 节点字段表单：`frontend/src/components/WorkflowNodeForm.vue`（列表编辑与画布面板共用同一份字段，避免两套 UI 漂移）

- 样式：同文件 `<style scoped>`（`.wf-palette` / `.wf-port` / `.wf-edge-*` / `.run-*`），移动端面板改为横向换行
