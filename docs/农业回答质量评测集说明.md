# 农业回答质量评测集

## 定位

本数据集评测的是**最终回答质量**，不是检索命中率，也不是后端单元测试。

- 检索评测：回答可能引用了正确资料，但生成内容仍可能跨作物/跨病害串段。
- 代码测试：验证接口、权限、RAG 流程、计费、附件等行为。
- 本评测：用金标准问题、参考事实和评分规则，端到端评价“发布版 Agent”的回答。

## 数据集

- 平台数据集：`农业回答质量金标准-60题`
- 数据集 ID：`93`
- 文件：`docs/农业回答质量评测集-60题.jsonl`
- 样本数：60

覆盖：

- 水稻、小麦、玉米、大豆、油菜、花生、马铃薯
- 蔬菜、苹果、柑橘、葡萄、茶树
- 施肥、冻害、涝害、干旱、药害
- 模糊问题、知识库边界、安全用药和拒答
- 明确禁止：跨作物/跨病害串段、编造资料、无登记药剂推荐、承诺治愈或产量

## 样本格式

```json
{
  "question": "小麦条锈病怎么防治？",
  "expectedAnswer": "发现一点防治一片；选用抗病品种、加强监测，发病初期选用戊唑醇、丙环唑、氟环唑等登记三唑类药剂，按标签使用。",
  "scoreCriteria": "必须点明小麦条锈病和“发现一点防治一片”；不得混入赤霉病或水稻病害；不得编造剂量。",
  "stepType": "ANSWER"
}
```

## 运行方式

使用平台“评测与运营 → 结果评测 → 数据集/任务”：

1. 选择 Agent `5422`
2. 选择数据集 ID `93`
3. 裁判模型优先使用独立模型；当前基线临时使用 `qwen2.5:7b-chat`
4. 通过阈值 `0.6`
5. 检查 `ANSWER` 步骤结果、平均分、通过率和失败样本原因

基线任务：`1463`

## 关注指标

- 回答事实正确率
- 引用命中率
- 跨作物/跨病害串段率
- 安全用药提示覆盖率
- 知识库边界/拒答正确率
- 人工抽检通过率

性能（首 token、P95）单独统计，不混入质量分。

## 已知基线风险

本地 `qwen2.5:7b-chat` 在长上下文下可能把相邻 RAG 片段拼接：

- 水稻纹枯病可能混入虫害生物防治
- 玉米南方锈病可能混入其他玉米病害的种子处理/井冈霉素措施

这类问题必须通过回答质量评测集暴露，不能只依赖检索关键词测试。
