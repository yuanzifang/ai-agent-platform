# 网关本地并发压测

日期：2026-10-30

## 场景

- 网关路由指向本地 mock 上游 `/always-ok`
- 上游和平台均在本机
- 绕过 Agent/LLM，只测网关转发、鉴权、WAF、日志链路
- 100 VU 恒定并发，持续 30 秒

## 运行

```bash
GATEWAY_URL=... GATEWAY_KEY=... VUS=100 DURATION=30s \
  k6 run scripts/gateway-k6.js
```

## 结果

```text
http_reqs: 143180
throughput: ~4103 req/s
http_req_failed: 0.66% (950/143180)
latency: avg 21.33ms, med 2.6ms, p(90) 32.73ms, p(95) 39.13ms, max 10.01s
k6 thresholds: 通过（失败率 <1%，p95 <500ms）
```

说明：

- 0.66% 失败全部落在极端尾延迟，k6 阈值仍通过
- 这是本机 mock 网关基准，不代表公网/上游真实服务 SLA
- 正式验收仍需真实上游、TLS、跨网络和长时间稳定性测试
