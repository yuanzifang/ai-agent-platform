## 二、审计留痕

- **操作审计**（audit_operation）：append-only + `prev_hash` SHA-256 哈希链（架构 8.4）。
  埋点：agent 发布/回滚/删除、会话删除/分享、成员邀请/角色变更/激活、平台开通租户/启停。
  实测：`agent.publish`、`member.invite` 落库，含操作人/IP/链指纹。
- **登录审计**（audit_login）：成功/失败 + IP + UA，累计 26 条，`/audit` 页面可查（租户内过滤）。

## 三、其他安全项

- **JWT_SECRET**：已从开发占位替换为 `openssl rand -hex 48` 强密钥（仅存 .env，gitignore）。
  轮换后旧 access token 全部失效；浏览器端由 refresh token（独立随机串）静默换新，无感恢复。
- **账号锁定**：连续失败锁定（lockedUntil，M1 已实现）。
- **密码策略**：BCrypt 存储；邀请激活/平台开通强制 ≥8 位。
- **会话附件/知识库上传**：类型与大小校验（12MB multipart / 10MB ASR）。
