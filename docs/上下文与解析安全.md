# 上下文预算与文档解析安全加固（2026-10-30）

本轮针对 RAG 截断、超大原子块、PDF 渲染内存和解压炸弹做显式防护。

## 1. RAG 独立预算与完整片段

- `ContextWindowService.fitSystemPrompt()` 识别 `<untrusted_retrieval>`，不再对整段系统提示做字符级 `substring`。
- RAG 片段使用 `ChatService.RAG_FRAGMENT_SEPARATOR` 分隔，正文里的 Markdown `---` 不会被误当成分片边界。
- 超预算时从尾部整片丢弃，只保留完整片段；结束标签始终闭合。
- 如果连一个片段都放不下，整块 RAG 省略，并写入“资料不完整”的系统提示，而不是留下半截不可信内容。
- RAG 之后的长期记忆等可信内容会保留，不会被截断逻辑丢弃。
- 流式响应发送 `notice` 事件，前端在消息下方显示截断提示；非流式响应返回 `ragTruncated=true`。
- RAG 目标预算占比可配置，默认 40%：

```yaml
llm:
  context:
    rag-budget-ratio: 0.4
```

## 2. 超大原子块与 embedding 输入上限

- Markdown 代码块超过 `TABLE_PART_SIZE`（1500 字符）时按行切分，每片保留原语言 fence 和闭合 fence。
- 管道表/HTML 表继续走 `MarkdownText.splitTable()`，按行切分并重复表头。
- 含 `rowspan` 表头等无法安全切分的 HTML 表保持原子，由 embedding 层显式报错，不再静默交给服务端截断。
- `EmbeddingService` 在调用上游前估算输入 token（CJK 1 字/token，其他 4 字符/token），超过上限直接返回 400：

```yaml
embedding:
  # 按实际 embedding 模型上下文配置；默认 8192
  max-input-tokens: 8192
```

## 3. PDF 渲染像素上限

- 所有 PDF 整页渲染统一走 `renderPdfPage()`：按页面物理尺寸计算目标像素数，超过上限时自动降低 DPI。
- 渲染结果再做一次像素兜底缩放；单页扫描件的内嵌图片在解码前按声明的宽高检查，
  超限时跳过原图 OCR 并回退到整页降级渲染，避免先分配巨型 ARGB。
- 默认上限 1600 万像素（约 64MB ARGB/张），适合 4 路并发 + `-Xmx1g`；可按机器调整：

```yaml
knowledge:
  pdf:
    max-render-pixels: 16000000
```

- 降级会记录到解析警告，便于人工复核 OCR 质量。

## 4. Office 解压炸弹防护

`DocumentParser` 静态初始化时显式设置 POI：

- 单个 zip entry 最大 64MB；
- 最小解压比 0.01（压缩后/解压后低于 1% 视为可疑）。

覆盖 DOCX/XLSX/PPTX 等 OOXML 文件，避免 20MB 上传解压出数 GB 内容打爆 1GB 堆。

## 5. 真实 PDF 样本回归（金融/物理化学）

公开样本已加入复测：Berkshire 年报、Apple 10-K、JPMorgan 年报截页、三篇物理化学/数学
arXiv 论文和 NIST SP 800-53。样本下载脚本：

```bash
bash scripts/download_pdf_samples.sh backend/target/pdf-samples
cd backend
PDF_BENCH_DIR="$PWD/target/pdf-samples" mvn -Dtest=PdfBenchmarkTest test
```

本轮同时修复了真实样本暴露的解析问题：

- 表格单元格按字形间距补空格，避免 `TableofContents` 这类粘连；
- 过滤目录/封面/签名页/长段正文框成的伪表格；
- 首页长标题不再被 80 字符上限误丢；
- 同页重叠且内容高度相似的表块去重。

结果和已知缺口见 `docs/PDF真实样本基准.md`。

## 6. 回归门禁

- `ContextWindowRagTest`：预算紧张时保留闭合边界和完整片段；边界不完整时剥离不可信内容；RAG 后的长期记忆不丢失。
- `MarkdownChunkerTest`：超大代码块切分且每个 fence 闭合。
- `EmbeddingServiceTest`：超模型输入上限时在本地报错。
- `DocumentParserTest`：A0 页面渲染像素不超过上限；ZipSecureFile 上限生效。
- `PdfSnapshotTest`：合成三页 PDF 的标题数、表格数、页码覆盖阈值；已接入 `.github/workflows/ci.yml`。

## 7. 仍有限制

- 含复杂 `rowspan`/多行表头且无法安全切分的大 HTML 表格仍保持原子；此类块超过 embedding 上限会明确失败，需要后续做版面区域切分。
- 无标题、列数超过 12 的金融表仍可能被质量门槛丢弃；正文文字保留，但表格结构会丢失。
- 扫描版医学/化学/合同 PDF 还需要真实样本做 OCR 与表格回归。
