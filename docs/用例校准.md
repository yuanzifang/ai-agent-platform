# 用例人工标注与裁判校准

对应“人工闭环”缺口：用例库原有审核/修正，本批次增加回归结果的人工标注队列与 LLM 裁判一致性统计。

## 1. 数据

V52 在 `test_case_run_item` 增加：

- `human_score`：人工评分 0~1（多标注时为均值）
- `human_label`：PASS / FAIL（多标注时为共识）
- `reviewer_id`
- `reviewed_at`
- `review_note`
- `label_count`：标注人数

V54 增加 `case_calibration_label`：

- 每条回归明细允许多个 reviewer 独立标注（唯一键 item+reviewer）
- item 上保存共识标签、平均分、标注人数
- 默认需要 2 个标注人才进入 DONE；PENDING 为标注数不足

每条模型回归明细保留 LLM 裁判分 `score`，人工标注独立存储，不覆盖裁判结果。

## 2. 接口

```http
GET /api/v1/cases/calibrations?status=PENDING|DONE|ALL&runId=&page=1&pageSize=20
GET /api/v1/cases/calibrations/stats
PUT /api/v1/cases/calibrations/{itemId}
```

标注请求：

```json
{"humanScore": 1, "humanLabel": "PASS", "note": "人工复核正确"}
```

- `humanLabel` 必填，PASS/FAIL；
- `humanScore` 省略时按标签补 1/0；
- 同一 reviewer 重复保存覆盖自己的标注；
- 多标注共识：多数 PASS/FAIL；平票按平均分 >=0.6 判 PASS；
- 保存写审计 `case.calibration`；
- 仅 `eval:manage`。

统计：

- `total/labeled/pending`（labeled=达到 min-annotators 的共识项）
- `agreementRate`：共识 PASS/FAIL 与裁判 `score>=0.6` 是否一致
- `meanAbsError`：共识平均分与裁判分的平均绝对差

## 3. UI

用例库工具栏新增「人工标注 / 校准」抽屉：

- 待标注/已标注/全部筛选
- 回归任务、候选模型、问题、候选回答、参考/期望
- 裁判分、人工分、PASS/FAIL、备注
- 一致率/平均分差/标注者两两一致率统计
- 保存后刷新队列

## 4. 抽检与指派

- `POST /cases/calibrations/sample {percent}`：按租户回归明细分页范围随机置 `sampled=1`，至少 1 条；
- `PUT /cases/calibrations/{id}/assign`：指派标注人，空 body 表示指派给自己；
- 列表支持 `mine=true`（只看我的）、`sampledOnly=true`（只看抽检）；
- 统计返回 `sampled/assigned`；
- V57 新增 `test_case_run_item.sampled/assignee_id`。

## 4.1 冲突仲裁

- 达成最小标注人数且同时出现 PASS/FAIL 时，明细 `arbitrationRequired=true`；
- 复核人（平台管理员 / OWNER / ADMIN）提交最终标签、分数、说明；
- 仲裁结果写入 `arbitrated_label/score/by/at/note`，统计优先使用仲裁标签；
- 新标注会清空旧仲裁，要求重新复核。

## 5. 盲标与一致性

- 校准接口支持 `blind=true`：隐藏裁判分/参考/裁判通过状态，前端有「盲标」开关；
- 统计新增 `interAnnotatorAgreement`：同一明细多个 reviewer 的 PASS/FAIL 两两一致率，`interAnnotatorPairs` 为样本对数。

## 6. 已验证

- `/cases/calibrations?status=PENDING` 返回待标注；
- PUT 人工 PASS 分=1；
- `/stats` labeled >=1；
- DONE 队列包含刚标注项；
- 后端单测 **51/51**、完整 E2E **29/29**（本批次前）。

## 7. 边界

- 已支持多人独立标注、共识、标注人数、盲标、标注者两两一致性、随机抽检、指派给自己；
- 已支持复核人仲裁；仍没有更细的复核层级、按成员分派后的负载均衡。
- 没有按评测数据集/生产 Trace 的抽样入队，只覆盖用例回归明细。
- 校准结果尚未自动调整裁判阈值或 prompt；目前只做统计。
