# 知识图谱

## 当前 MVP（2026-10-24）

- V60 新增 `knowledge_graph_entity` / `knowledge_graph_relation`；
- 知识库维度实体与关系：
  - 实体：名称、类型、描述、可选文档/分段来源；
  - 关系：起点、终点、关系名、权重、可选文档来源；
- API：
  - `GET /knowledge-base/{id}/graph`
  - `POST/PUT/DELETE /knowledge-base/{id}/graph/entities...`
  - `POST/DELETE /knowledge-base/{id}/graph/relations...`
- 权限：查看图谱用知识库可见权限，编辑用知识库编辑权限；
- 前端：知识库详情 →「知识图谱」，实体/关系编辑 + SVG 环形可视化；
- 删除知识库/文档时同步清理图谱数据与关系；
- E2E：实体新增/重复冲突/关系/更新/删除/计数/删除知识库。
- AI 抽取：`POST /knowledge-base/{id}/graph/extract`，支持粘贴文本或读取前 5 个分段，先预览、`commit=true` 后入库；最多 30 实体/50 关系；自动去重。
- 完整性：V62 将 `entity_type` 归一为 `NOT NULL DEFAULT ''`，同名无类型实体可被唯一键去重；关系增加 `(tenant, kb, from, to, relation)` 唯一键。
- 删除文档：同时删除两端实体属于该文档的关系，避免跨文档孤儿边。
- `weight` 语义：关系强度/置信度，范围 0.01–99.99。
- **GraphRAG MVP**：检索后匹配查询/命中文本中的实体名，沿最多 2 跳关系扩展，拉取实体显式关联的 chunk（`chunk_id`），按 Chunk ACL 过滤后追加，metadata 标记 `graph=true`、`entity_name`、`reason`（related1/related2）；最多追加 5 个 chunk。

当前是图谱数据、AI 抽取、可视化与 1 跳 GraphRAG MVP；检索主链路仍是向量/关键字，图谱作为补充召回。
