# 知识图谱

## 当前 MVP（2026-10-24）

- V60 新增 `knowledge_graph_entity` / `knowledge_graph_relation`；
- 知识库维度实体与关系：
  - 实体：名称、类型、描述、可选文档/分段来源；
  - 关系：起点、终点、关系名、权重、可选文档来源；
- API：
  - `GET /knowledge-base/{id}/graph`
  - `POST/PUT/DELETE /knowledge-base/{id}/graph/entities...`
  - `POST/DELETE /knowledge-base/{id}/graph/relations...`
- 权限：查看图谱用知识库可见权限，编辑用知识库编辑权限；
- 前端：知识库详情 →「知识图谱」，实体/关系编辑 + SVG 环形可视化；
- 删除知识库/文档时同步清理图谱数据与关系；
- E2E：实体新增/重复冲突/关系/更新/删除/计数/删除知识库。

## 未完成
