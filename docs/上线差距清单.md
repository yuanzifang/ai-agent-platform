## 七、MVP 判定标准

1. 一个未接触过项目的客户，从注册到发布 Agent 全程无开发者介入；
2. 性能、备份、安全均有实测数据；
3. 内测租户在真实场景连续运行 ≥ 2 周。

三条全满足，才算 MVP 产品。
