# 上线差距清单（MVP 基线）

更新：2026-10-23。本文是**上线门槛的唯一基线**，条目均经代码/环境核验（核验日期同日）。
证据型现状见 `docs/交付现状.md`（只记代码/实跑证据）；本文只记**离"能给真实客户用"还差什么**。
两文档之外的状态清单（含桌面环境信息.md）一律以本文为准，发现矛盾以本文 + 交付现状为准。

**总体估计**：1–2 人计，上线门槛约 4–6 周；加 3–5 个内测租户试点约 8 周（不含法务）。

## 一、上线阻断项（不做不能对外）

### 1. 部署从未实跑（约 3–5 天）
- 本机无 Docker/kubectl（仅 helm）。Compose `up`、Helm `install` 均未实跑。
- 仓库无 git remote，GitHub CI 从未在真实 Runner 上跑过（现有 CI 仅构建 + Mock E2E）。
- 交付现状.md 明确标注"不得说已验证可部署"。

### 2. 性能无实测数据（约 3–5 天）
- 需求 4.1 已列指标（首 Token < 2s、检索 < 500ms、审核 < 200ms、列表 < 1s 等，需求文档 6315 行起）；M6 出口标准含压测（8644 行）。
- 现状：已有 `scripts/perf-baseline.sh` 与 `docs/性能基线.md`（20 并发/200 请求，0 失败，p99 10–37ms，本机开发基线）；仍缺 k6 长稳/首 Token/RAG/审核/SSE 压测，**不能作为上线验收依据**。
- 数据口径注意：`billing_usage` 中 V20 之前的 64 条历史记录 cost 为 NULL，压测与成本报表需排除或归零处理（V40 已将历史 NULL 归零，需确认口径一致）。

### 3. 技能脚本进程级隔离（约 1–2 周，或先临时关闭）
- 多租户执行用户代码且无网络限制，脚本可直探本机 MySQL/Redis/MinIO，绕过全部 SSRF 防护——最大单点安全风险。
- 止血：SaaS/Compose/Helm 默认已改为 `SKILL_SCRIPT_ENABLED=false`；本地开发仍可显式开启；容器执行器完成后再开。

### 4. 无安全扫描（依赖扫描约 1 天，渗透测试约 1 周）
- 已落 `.github/workflows/security.yml`：gitleaks/Trivy/npm audit；**GitHub Actions 未实跑**。
- 仍缺 CodeQL 与第三方渗透测试；M6 越权矩阵 11/11 为开发者自测，不能替代渗透测试。

### 5. 备份容灾低于需求（约 1 周）
- 需求 4.3：99.9% 可用、RTO ≤ 4h、RPO ≤ 1h。
- 现状：backup.sh 已抓取 binlog 坐标（PITR 原料）并做过本地严格恢复演练；**缺**：异地副本、binlog 随备份归档（现仅坐标）、恢复时长实测达标。

### 6. 告警无人接收（约 2–3 天）
- alerts.yml（deploy/observability/）已写好，但 Prometheus/Alertmanager 容器未运行，规则从未 firing，无值班路由。
- 快速路径（第 1 周即可有人收告警）：用已实测的 AlertWebhookService 直推钉钉/企微群（6fa86db）；Alertmanager 作为二期。

## 二、需求条款仍不满足

### 7. 全局搜索
- 已实现顶栏跨 Agent/知识库/用例/工具搜索（前端并行调用现有 API + 跳转 + UI 冒烟）；未做统一后端聚合/相关度排序。

### 8. 双语只完成基础层
- 一级页面 + 主要业务页已接 vue-i18n（至 27b06d7 审计/用量页）；后端消息未国际化（无 messages*.properties / LocaleResolver）。时区/日期本地化未核实。

### 9. 浏览器兼容仅 Chromium
- 需求 5.1 要求 Chrome + Edge 最新两个大版本；Playwright 目前仅 Chromium，需补 msedge 渠道。

### 10. 合规文本与模型数据政策（法务为主）
- 隐私政策、用户协议、数据出境判断需法务介入。
- **模型数据留存/训练政策未标注**（已核验：模型选择处无任何 privacy/训练相关字段）。需按真实供应商条款逐家整理并在模型选择处展示，避免租户在不知情下将数据提供给训练。（注意：此前有说法引用"OpenCode Go / Gemini 4 Argon / Muse Spark"条款，该证据为虚构，已删除——关切成立、证据必须用真实供应商条款。）

## 三、产品化（MVP 最大不确定性）

### 11. 无真实用户验证
- 全部验证为开发者自测。上线前至少 3–5 个内测租户，真实场景跑 2–4 周。

### 12. 缺面向用户的文档
- README（150 行）面向部署/开发。缺：租户管理员手册、Agent 搭建教程、API 接入文档（swagger 已有，缺指南）、MCP 接入文档、FAQ。

### 13. 渠道与 MCP 仅 Mock 验证
- `agent_channel` = 0、`mcp_server` = 0（2026-10-23 查库）。飞书/企微/钉钉真实凭据与回调域名、真实 MCP Server 联调均为零。若 MVP 卖点含渠道/集成，必须真机联调。

## 七、MVP 判定标准

1. 一个未接触过项目的客户，从注册到发布 Agent 全程无开发者介入；
2. 性能、备份、安全均有实测数据；
3. 内测租户在真实场景连续运行 ≥ 2 周。

三条全满足，才算 MVP 产品。
