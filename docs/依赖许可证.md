## 策略（个人开发者可执行版）

- 允许清单：Apache-2.0、MIT、BSD、ISC、0BSD、EDL、CC0、MIT-0
- 需评审/保留声明：EPL/LGPL 等弱 copyleft、双许可、GPL+CPE
- 阻断：AGPL、SSPL、GPL-only、UNLICENSED、unknown
- 当前 280 条许可证记录：0 blocked、6 warning（dompurify MPL/Apache 双许可、Logback/LGPL、JSqlParser、Jakarta/Angus）
- CI 生成 `frontend-licenses.json` + `backend/target/licenses/THIRD-PARTY.txt`，运行 `scripts/license_policy.py` 门禁
- 不做法务签字；由项目 owner 自查并保留 `THIRD-PARTY-NOTICES.md`。商业化/收费分发前建议再做一次正式合规审查。

## 仍缺

- 个人 owner 自查完成；商业化/收费分发前建议正式合规审查
- SBOM（CycloneDX/SPDX）与完整许可证文本随分发物归档仍未做
- 前端 devDependencies 与生产依赖的进一步分层审计

## 复现

```bash
cd backend
mvn org.codehaus.mojo:license-maven-plugin:2.5.0:add-third-party \
  -Dlicense.outputDirectory=target/licenses \
  -Dlicense.excludedScopes=test \
  -Dlicense.includeTransitiveDependencies=true

cd ../frontend
trivy fs --scanners license --format json --output ../frontend-licenses.json --exit-code 0 package-lock.json

cd ..
python3 scripts/license_policy.py frontend-licenses.json backend/target/licenses/THIRD-PARTY.txt
```
