# 依赖许可证基线

日期：2026-10-27  
工具：Maven license-maven-plugin 2.5.0（后端 193 个依赖）+ Trivy 0.76.1（前端 package-lock）

## 前端

| 许可证 | 数量 |
|---|---|
| MIT | 77 |
| BSD-3-Clause | 4 |
| Apache-2.0 | 2 |
| BSD-2-Clause / ISC / 0BSD | 各 1 |
| MPL-2.0 OR Apache-2.0 | 1（dompurify） |

未发现 GPL / AGPL / unknown。

## 后端

193 个直接+传递依赖，主要为 Apache-2.0、MIT、BSD、EDL、EPL。

需要法务/合规确认的弱 copyleft/双许可项：

- Logback classic/core：EPL-2.0 / LGPL-2.1-only（未修改、作为库使用）
- JSqlParser：LGPL-2.1 / Apache-2.0 双许可
- Jakarta Annotations、Angus Mail：EPL-2.0 / GPL-2.0 with CPE / EDL 双许可
- Bouncy Castle Licence、CC0、MIT-0 等已列入清单

未发现 AGPL。

## 策略

- 允许清单：Apache-2.0、MIT、BSD、ISC、0BSD、EDL、CC0、MIT-0
- 需评审：EPL/LGPL 等弱 copyleft、双许可、GPL+CPE、未知许可证
- 禁止直接引入 AGPL，除非有明确法务批准
- 生成文件：`backend/target/licenses/THIRD-PARTY.txt`（CI 产物，不入库）

## 仍缺

- 法务最终确认（尤其 Logback LGPL/EPL、Jakarta/Angus 双许可）
- 许可证文本随分发物归档、SBOM（CycloneDX/SPDX）
- 前端 devDependencies 与生产依赖的进一步分层审计

## 复现

```bash
cd backend
mvn org.codehaus.mojo:license-maven-plugin:2.5.0:add-third-party \
  -Dlicense.outputDirectory=target/licenses \
  -Dlicense.excludedScopes=test \
  -Dlicense.includeTransitiveDependencies=true

cd ../frontend
trivy fs --scanners license --format table --exit-code 0 package-lock.json
```
