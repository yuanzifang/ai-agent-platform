# AI Agent 平台用户手册

本文面向租户管理员和 Agent 搭建者。部署、架构和运维文档见 `docs/` 下对应专题。

## 1. 快速开始

1. 打开平台地址，使用管理员分配的账号登录。
2. 进入「工作台 → Agent 列表」，点击「新建 Agent」。
3. 配置模型、提示词和可选的知识库/工具。
4. 保存后先「对话」调试，再「发布」生成版本。
5. 在「评测与运营 → 评测中心」建立数据集并运行评测。

角色建议：

| 角色 | 典型权限 |
|---|---|
| OWNER | 租户配置、成员、发布/强制发布 |
| ADMIN | 管理成员、模型、知识库和 Agent |
| MEMBER | 创建/编辑自己的 Agent，使用已授权资源 |

## 2. 租户管理员

### 成员与权限

- 「管理 → 用户管理」邀请成员、分配角色和状态。
- 「管理 → 租户管理」查看租户信息、配额和可见范围。
- Agent 可见性支持 `TENANT` / `PRIVATE`；私有 Agent 需要单独授权。
- 知识库支持库级和 chunk 级权限；只把需要的知识库授权给成员。

### 模型与计费

- 「管理 → 模型接入」配置 Provider（OpenAI 兼容 / DeepSeek / Anthropic / Ollama / Gemini OpenAI 兼容等）。
- 「管理 → 系统设置」维护全局配置，包括：
  - `publish.gate-threshold`：发布门禁阈值
  - `eval.gate-judge-model`：门禁裁判模型；留空使用启动参数
  - `knowledge.parse.*`：OCR/视觉默认值
- 「计费」查看模型价格、租户用量和月度限额。
- 本地 Ollama 模型可标记为 `PLATFORM`，只用于平台评测/裁判，不会出现在 Agent 模型选择中。

### 审计与告警

- 「可观测 → 审计日志」查看操作审计和哈希链校验。
- 「可观测 → 监控统计」查看请求、Token、延迟和错误。
- 平台管理员可在系统设置或环境变量配置群机器人告警。

## 3. 搭建 Agent

### 3.1 基础配置

- **名称/描述**：用于列表和广场展示。
- **模型**：Agent 回答使用该模型；平台本地模型不会自动替代。
- **提示词**：定义角色、边界和输出格式；支持 `{{变量}}` 占位符。
- **变量**：为提示词设置默认值和必填校验。
- **思考模式**：仅模型能力声明支持时生效。

### 3.2 知识库

- 在「资产 → 知识库」上传 PDF/Office/Markdown/TXT 等文档。
- 支持 OCR、表格结构、页码/父块、有效期、chunk 权限和重复文件复用。
- Agent 编辑页勾选知识库；检索模式可选向量/关键词/混合。
- 解析失败可在文档列表重试，或对存量文档发起批量升级。

### 3.3 工具、技能、子 Agent

- 工具：API、MCP、内置工具（当前为 calculator/current_time）。
- 技能：提示词/脚本能力；生产建议使用容器脚本运行时。
- 子 Agent / HANDOFF / 工作流：用于多 Agent 编排。
- 写工具默认需要显式允许；生产建议收紧 ALLOWLIST 和参数限制。

### 3.4 发布与回滚

- 发布前会按配置完整性提示；发布生成不可变版本。
- 配置 `eval.gate-threshold` 后，发布前会运行预发布门禁；任一步骤通过率低于阈值会阻断。
- 失败明细可在任务详情和发布弹窗查看；OWNER/ADMIN 可强制发布。
- 「版本」可查看、回滚；已部署 Agent 发布后可自动重新部署。

## 4. 对话与调试

- Agent 编辑页「对话」用于当前配置调试，不会自动发布。
- 对话支持 SSE 流式、停止、续传、工具步骤、附件和引用。
- 用户点踩会沉淀到用例库，可人工审核后转成回归用例。

## 5. 评测中心

### 数据集

- 支持 `ANSWER / REWRITE / RETRIEVAL / RERANK` 步骤样本。
- 样本可配置期望答案、评分标准、`expectedPayload` 和 `stepConfig`。
- 支持 JSONL 导入、单条编辑和删除。

### 单步试跑

- 顶部「单步试跑」可即时运行：
  - ANSWER：选择 Agent，使用其发布配置回答并裁判
  - REWRITE：可指定模型；可选“仅本地规则改写”
  - RETRIEVAL / RERANK：需要 knowledgeBaseId 和期望 chunk
- 不创建评测任务，适合调整样本和检索配置。

### 任务与回归

- 一次性评测：选择 Agent + 数据集，异步执行。
- 任务详情展示分步骤汇总、失败明细、趋势和人工复核。
- 可选择一个基线任务做分步骤回归对比。
- 发布门禁会检查各步骤通过率，阈值来自 `publish.gate-threshold`。

## 6. API 接入

### 认证

```http
POST /api/v1/auth/login
Content-Type: application/json

{"username":"dev","password":"******","tenantKey":"dev"}
```

响应中的 `accessToken` 放入：

```http
Authorization: Bearer <accessToken>
```

Access Token 过期后使用 HttpOnly Refresh Cookie 刷新；不要把密码或 Token 写进代码仓库。

### 调用示例

```bash
curl -s http://localhost:8080/api/v1/agent \
  -H "Authorization: Bearer $TOKEN"
```

OpenAPI/Swagger 由后端提供，具体路径以部署环境为准。流式对话使用 SSE：

```http
POST /api/v1/conversations/{id}/messages
Accept: text/event-stream
{"message":"你好","stream":true}
```

错误响应格式：

```json
{"code":400,"message":"...","data":null,"traceId":"..."}
```

### 集成网关

- 平台统一 API 网关支持 API Key、转发、限流、超时重试、日志和主备。
- Agent 运行时网关支持 OpenAI 兼容代理、令牌、日配额、多副本 Redis 共享。
- 生产调用建议使用独立 API Key 和最小权限。

## 7. MCP 接入

1. 「资产 → MCP Server」添加 Server。
2. 选择传输方式（HTTP/SSE 或 stdio），填写地址/命令。
3. 同步 tools/resources/prompts，选择需要暴露的工具。
4. 在 Agent 中绑定工具，并确认写操作策略。
5. 真实第三方 MCP 需要网络白名单和凭据；平台只做客户端，不托管第三方服务。

## 8. 常见问题

**登录 401/500？**  
检查后端健康、数据库迁移和账号状态；若数据库刚恢复，确认 Flyway 与备份版本。

**Agent 发布被阻断？**  
查看任务详情中的门禁失败步骤和失败样本；先修样本或检索配置，必要时 OWNER/ADMIN 强制发布。

**检索没有结果？**  
确认知识库已解析完成、文档在有效期内、Agent/用户有权限、embedding 模型一致。

**本地模型不可选？**  
本地平台模型用途是 `PLATFORM`，不会出现在 Agent 模型下拉；可在评测裁判或单步试跑中使用。

**上传重复文件？**  
平台会按 SHA256/解析配置指纹提示复用；跨租户不复用。

**备份怎么恢复？**  
先看 `docs/备份与恢复.md`；生产恢复前停止写入并做当前快照。PITR 必须恢复到临时库验证后再切换。

## 9. 安全建议

- 生产更换 JWT/AES/数据库/MinIO 默认密钥。
- 只开放 80/443；MinIO 控制台和数据库不暴露公网。
- 生产关闭 `SKILL_SCRIPT_ENABLED` 或切换 docker 沙箱运行时。
- 工具访问内网时使用 `TOOL_ALLOWED_HOSTS` 白名单，保持 `TOOL_ALLOW_PRIVATE=false`。
- 对高风险写工具使用 ALLOWLIST 与人工确认。
- 定期做备份恢复演练、告警值班和权限复核。
