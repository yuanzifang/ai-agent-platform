# 图片多模态理解

## 1. 开关

```yaml
knowledge:
  vision:
    enabled: ${KNOWLEDGE_VISION_ENABLED:false}
    endpoint: ${KNOWLEDGE_VISION_ENDPOINT:http://127.0.0.1:11434}
    model: ${KNOWLEDGE_VISION_MODEL:qwen3-vl:32b}
    timeout-seconds: ${KNOWLEDGE_VISION_TIMEOUT_SECONDS:180}
    max-images: ${KNOWLEDGE_VISION_MAX_IMAGES:3}
```

默认关闭；OCR 与多模态可独立开启。

## 2. 行为

- 解析文档时提取 DOCX/PPTX/PDF 内嵌图片；
- 对最多 `max-images` 张图片调用 Ollama `/api/generate`；
- 图片描述以 `【图片说明】...` 作为独立分段，参与 embedding、PgVector 入库和检索；
- 单张失败只记录日志，不阻断正文/OCR 入库；
- 原图仍由 `knowledge_document_image` 保存并可预览。

## 3. 已验证

- 本机 `qwen3-vl:32b` 对扫描 PDF 内图片返回“图片中的文字内容为 IMG 2468”；
- 文档解析为 2 个分段：OCR 正文 + `【图片说明】`；
- 测试知识库已删除，图片/分段/向量清理。

## 4. 边界

- 依赖本地 Ollama 视觉模型，首次加载较慢（约 28 秒）；
- 不是逐图人工审核，描述质量取决于模型；
- 大图/多图会显著增加解析耗时，默认最多 3 张。
