# 知识库内容能力现状（2026-10-21）

## 已实现/已实测

- DOCX/PPTX/XLSX/XLS/PDF/HTML/MD/TXT/CSV/JSON 解析；
- 父子分块（父约 2000、子 500/50）；
- XLSX/XLS 表格转 HTML，保留合并单元格 `colspan/rowspan`；
- DOCX/PPTX 表格仍为 Markdown 行（单元格文本保留，合并语义未保留）；
- EPUB：ZIP + XHTML/HTML 正文提取；
- 扫描版 PDF/图片 OCR 接口：PDFBox 渲染 + 外部 tesseract；
- **真实 tesseract 验收**：
  - 本机安装 tesseract 5.5.3 + chi_sim/eng；
  - Java AWT 生成含 `INVOICE 1234.00` 的 PNG；
  - `DocumentParserTest.realTesseractOcrOnRenderedImage` 实际调用 tesseract，识别出 `1234`；
  - 单测 **54/54**。
- **XLSX 合并单元格测试**：A1:B1 合并解析为 `<td colspan="2">`；
- **EPUB 测试**：ZIP 内 XHTML 正文提取；
- **真实 bge-m3 / 1024 维验收**：
  - 本机 `ollama pull bge-m3`（1.2GB）；
  - 创建 `embeddingModel=bge-m3` 知识库，上传 txt → 回调 → 解析 DONE；
  - PgVector `tenant_1.embeddings_1024` 写入 1 行，metadata embedding_model=bge-m3；
  - `/knowledge-base/{id}/search` 向量检索命中“退款政策”；
  - 测试 KB 已删除，`embeddings_1024` 计数恢复 0。
