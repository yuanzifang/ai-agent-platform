# 知识库内容能力现状（2026-10-25）

## 已实现/已实测

- DOCX/PPTX/XLSX/XLS/PDF/HTML/MD/TXT/CSV/JSON 解析；
- 父子分块（父约 2000、子 500/50）；
- XLSX/XLS 表格转 HTML，保留合并单元格 `colspan/rowspan`；
- DOCX 表格转 HTML，保留 gridSpan/vMerge 的 `colspan/rowspan`；
- PDF 元数据（标题/作者/主题/关键词/页数）进入 `[PDF元数据]` 分段；
- PDF 书签目录（`[书签]`，最多 100 条）、超链接（`[链接]`）、内部跳转（`[跳转]第N页`）
  与内嵌附件名称/正文（`[附件]` / `[附件正文]`，最多 5 个、单个 5MB、正文截取 5000 字）进入解析文本；
- 加密 PDF 明确返回 422「PDF 已加密，请先解除密码后再上传」，不进入解析；
- PDF 表单字段（`[表单]字段: 值`）、XFA XML 文本（`[XFA]`）与批注内容（`[批注]`）进入解析文本；
- PDF 内联图片（`BI...ID...EI`）与 XObject 位图均可提取；DOCX/PPTX/PDF 内嵌图片可选 OCR，文本以 `[图片OCR]` 注入解析结果（最多 20 张，默认 OCR 开启时生效）；
- 图片原文件保存到 MinIO `knowledge_document_image`，文档图片 API 返回 10 分钟预签名 URL，知识库详情可预览；
- **批量上传/覆盖上传**：知识库详情支持一次选择多个文件；逐文件 XHR 进度（上传中/解析中/完成/失败）；
  已完成/失败文档可重新上传覆盖，复用同一文档 ID，清理旧分段/向量/图片与旧对象后重新解析；
  后端 callback 用 `documentId` 区分新增/覆盖；CSP 允许配置的 MinIO 直传 origin；
- 可选图片多模态理解：`knowledge.vision.enabled=true` 时调用本地 Ollama `qwen3-vl:32b`，图片描述以 `【图片说明】` 独立分段入库并可检索（默认关闭，失败不影响正文）；
- XLSX/PPTX 图表结构化：提取图表标题、系列、类目、数值点，以 `[图表]` 文本进入分块与检索；
- **PDF 文本层表格重建**：按字符坐标分行/分列，满足“至少 3 行、最多列数至少 3、列起始位置跨行对齐”时
  输出 `<table border="1">` HTML，保留行列关系；按列锚点补空单元格 `<td></td>`；最多处理前 50 页；
  普通正文不会误判为表格；
- **PDF 多行单元格**：同一单元格换行产生的续行，按行高与列锚点合并回上一逻辑行，
  避免续行被拆成新表格行；
- **PDF 图表/照片案例**：
  - 内嵌位图：从 PDF XObject 提取图表、照片，最多 20 张，落 MinIO 并可由 OCR/多模态描述；
  - 矢量图表：检测到至少 6 次绘制操作时，整页渲染为 150DPI PNG，
    交给 OCR 或多模态理解；即使同页已有照片/位图也独立检测，避免组合页漏图表；
    标签文本仍由 PDF 文本层保留；
  - 已验证 `chart-photo.pdf`（图表+照片两张内嵌图）、`vector-chart.pdf`（矢量柱状图）
    与 `mixed-photo-vector.pdf`（同一页照片+矢量图表，提取照片并额外渲染组合页）单测；
- **PDF 跨页表格**：上一页表格接近页底、下一页内容接近页顶时，续页 1–2 行也会并入同一
  `<table>`；支持列位置平移、新增列，以及按表头名称处理列插入/删除/换序（要求表头唯一、至少 2 个共同列）；
  重复表头自动去重；已验证 `cross-page.pdf`、平移列、新增 Discount 列和换序 Discount 列单测；
- **扫描版 PDF 表格**：tesseract 输出 TSV，按 OCR 词框重建行/列和 `<table>`；同时保留 OCR 纯文本；
  支持表头 `<thead>/<th>`、多级表头 colspan、非数值列 rowspan（≤50 行）、caption、
  脚注 `<p class="table-note">`；两列表格需至少 4 行，降低双栏正文误判；
  相邻扫描页表头一致时去重表头并合并 `<tbody>`；简单表（无 colspan/rowspan）支持按表头名称
  处理跨页列插入/删除/换序；
  已验证真实 tesseract 的 `scan-table.pdf`、`scan-table-caption.pdf`、
  `scan-table-multi-header.pdf`、`scan-table-rowspan.pdf`、两列 `scan-table-two-column.pdf`
  与跨页 `scan-table-cross-page.pdf`、换列 `scan-table-column-change.pdf` 单测；
- **低对比度扫描预处理**：OCR 前灰度化、对比度拉伸、小图 2x 放大（`knowledge.ocr.preprocess` 默认 true）；
  已验证浅灰文字表格单测；不替代倾斜校正/专业去噪；
- **强噪点预处理**：检测椒盐噪声占比，超过阈值时自适应 3x3/5x5 中值滤波
  （`knowledge.ocr.denoise` 默认 true）；已验证 0.2% 噪点表格单测；
- **扫描页方向纠正**：tesseract OSD 检测 90/180/270 旋转并在 OCR 前转回正向
  （`knowledge.ocr.auto-orient` 默认 true）；已验证旋转 90° 的表格 PDF 单测；
- **小角度倾斜校正**：灰度投影方差在 -8°～8° 内寻找最佳角度（`knowledge.ocr.deskew` 默认 true）；
  已验证 6° 倾斜表格单测；强噪点/透视变形仍不保证；
- **PDF 表格标题/脚注**：表格上方 `Table/表/Figure/图` 行输出 `<caption>`；表格下方
  `Note/注/Source/来源/*` 行最多输出 3 条 `<p class="table-note">`；已验证多行脚注单测；
- **PDF 多级表头**：首个数值数据行之前的连续非数值行输出 `<thead>`/`<th>`；表头缺列时按列锚点
  推断 `colspan`；支持 2024/2025 年份型表头行；已验证两行和年份型表头单测；
- **PDF 纵向合并（保守）**：非数值列、最多合并 50 行；后续行该列为空且其他列有内容时推断
  `rowspan`；已验证首列、中间列、4 行与 12 行分组单测；

## 仍未完成

- 复杂 PPTX 合并单元格的边界情况（嵌套/不规则合并）仍需更多真实样本；
- PDF 矢量图表的数据序列还原（当前渲染页面后交给 OCR/多模态描述，不能保证还原每个数据点）；
- PDF 图表数值/系列的高可信结构化还原（真实 qwen3-vl 已能描述趋势，但可能误读数据点）；
- PDF 复杂表格：跨网格合并、重复表头名称/无共同表头的跨页表尚未完整支持；
  非数值列 rowspan（≤10 行）、简单两级表头、跨页续表（含列位置平移）、标题/脚注已支持；
- 扫描版 PDF 的复杂表格（跨网格合并、带合并单元格的列变化）尚未验证；
- 两列扫描表格已支持（≥4 行），更少行数的两列表格不结构化；
- 大文档/大表格性能与内存压测。
