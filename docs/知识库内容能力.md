# 知识库内容能力现状（2026-10-25）

## 已实现/已实测

- DOCX/PPTX/XLSX/XLS/PDF/HTML/MD/TXT/CSV/JSON 解析；
- 父子分块（父约 2000、子 500/50）；
- XLSX/XLS 表格转 HTML，保留合并单元格 `colspan/rowspan`；
- DOCX 表格转 HTML，保留 gridSpan/vMerge 的 `colspan/rowspan`；
- PDF 元数据（标题/作者/主题/关键词/页数）进入 `[PDF元数据]` 分段；
- PDF 书签目录（`[书签]标题（第N页）`，最多 100 条）、超链接（`[链接]`）、直接/命名目标内部跳转
  （`[跳转]第N页`）与内嵌附件名称/正文（`[附件]` / `[附件正文]`，最多 5 个、单个 5MB、正文截取 5000 字）进入解析文本；
- **加密 PDF**：上传解析设置可填写 PDF 密码；文档列表可打开“PDF 密码”对话框更新密码并重解析，
  无需覆盖重传；密码使用 AES-GCM 加密后保存在文档级 `parse_config`，解析/重解析时解密使用，
  不写入日志或知识库级配置；密码缺失/错误返回 422；仅支持文档级密码，URL 导入暂不支持；
  AES 密钥变更后旧密码无法解密，需要重新上传；
- PDF 表单字段（`[表单]字段: 值`）、XFA XML 文本（`[XFA]`）与批注内容（`[批注]`）进入解析文本；
- **动态 XFA 数据集**：解析 `xfa:datasets/xfa:data`，输出 `[XFA数据]路径: 值`，
  重复子节点使用 `[n]` 编号，最多 200 个字段；同时从 XFA template 提取
  `[XFA字段]子表单.字段 (标签)`，用于 datasets 为空的动态表单；仅提取数据/字段，
  不执行 XFA 布局/脚本渲染；
- PDF 内联图片（`BI...ID...EI`）与 XObject 位图均可提取；DOCX/PPTX/PDF 内嵌图片可选 OCR，文本以 `[图片OCR]` 注入解析结果（最多 20 张，默认 OCR 开启时生效）；
- 图片原文件保存到 MinIO `knowledge_document_image`，文档图片 API 返回 10 分钟预签名 URL，知识库详情可预览；
- **批量上传/覆盖上传**：知识库详情支持一次选择多个文件；逐文件 XHR 进度（上传中/解析中/完成/失败）；
  已完成/失败文档可重新上传覆盖，复用同一文档 ID，清理旧分段/向量/图片与旧对象后重新解析；
  后端 callback 用 `documentId` 区分新增/覆盖；CSP 允许配置的 MinIO 直传 origin；
- 可选图片多模态理解：`knowledge.vision.enabled=true` 时调用本地 Ollama `qwen3-vl:32b`，图片描述以 `【图片说明】` 独立分段入库并可检索（默认关闭，失败不影响正文）；
- XLSX/PPTX 图表结构化：提取图表标题、系列、类目、数值点，以 `[图表]` 文本进入分块与检索；
- **PDF 文本层表格重建**：按字符坐标分行/分列，满足“至少 3 行、最多列数至少 3、列起始位置跨行对齐”时
  输出 `<table border="1">` HTML，保留行列关系；按列锚点补空单元格 `<td></td>`；最多处理前 50 页；
  普通正文不会误判为表格；
- **带边框 PDF 表格结构**：从 addRect 单元格矩形还原真实 colspan/rowspan；同页多个
  互不相连的矩形表格会按矩形连通关系分组，分别输出；
- **线条绘制表格结构**：收集横竖线构建网格，缺失内部线视为合并单元格，支持表头跨列/数据跨行；
  带边框表格优先于线条网格，线条网格优先于纯文本坐标推断；线条网格会把同一行列上的短线段
  按小间隙合并，支持文本层虚线/点线/轻折断网格；同一页多个互不相连的线条表格会按线段连通分组
  分别输出；网格表格识别 1–3 行表头，
  输出 `<thead>/<th>` 和 `<tbody>/<td>`，支持两级年份/子表头及跨页同表头合并；
  表格上下的 `Table/表` 标题和 `Note/注/来源` 脚注会分别输出 `<caption>` 与
  `<p class="table-note">`；
- **PDF 网格表格跨页合并**：矩形单元格/线条网格表格在相邻页表头一致时去重表头并合并数据行；
  已验证两页线条网格表格合并单测；
- **PDF 多行单元格**：同一单元格换行产生的续行，按行高与列锚点合并回上一逻辑行，
  避免续行被拆成新表格行；
- **PDF 图表/照片案例**：
  - 内嵌位图：从 PDF XObject 提取图表、照片，最多 20 张，落 MinIO 并可由 OCR/多模态描述；
  - 矢量图表：检测到至少 6 次绘制操作时，整页渲染为 150DPI PNG，
    交给 OCR 或多模态理解；即使同页已有照片/位图也独立检测，避免组合页漏图表；
    标签文本仍由 PDF 文本层保留；
  - 已验证 `chart-photo.pdf`（图表+照片两张内嵌图）、`vector-chart.pdf`（矢量柱状图）
    与 `mixed-photo-vector.pdf`（同一页照片+矢量图表，提取照片并额外渲染组合页）单测；
- **PDF 跨页表格**：上一页表格接近页底、下一页内容接近页顶时，续页 1–2 行也会并入同一
  `<table>`；支持列位置平移、新增列，以及按表头名称处理列插入/删除/换序（要求表头唯一、至少 2 个共同列）；
  重复表头自动去重；矩形/线条网格表格同样按相同表头跨页合并；
  已验证 `cross-page.pdf`、平移列、新增 Discount 列和换序 Discount 列单测；
- **扫描版 PDF 表格**：tesseract 输出 TSV，按 OCR 词框重建行/列和 `<table>`；同时保留 OCR 纯文本；
  支持表头 `<thead>/<th>`、多级表头 colspan、非数值列 rowspan（≤50 行）、caption、
  脚注 `<p class="table-note">`；两列表格需至少 4 行，降低双栏正文误判；
  扫描表格会检测页面图像横竖线；实线检测不到时回退长虚线/小间隙断裂线合并，
  支持表头/数据区 colspan、rowspan 及二者组合，输出 `<thead>/<th>` 表头并保留表格标题/脚注；
  已用真实 tesseract 的
  `scan-table-grid-spans.pdf` 验证两级表头（`Product` 跨两行、`Sales` 跨两列、年份子表头）、
  `Fruit` 跨两行及 caption/note；
  无网格或未检测到合并时仍回退到 TSV 文本重建；
  相邻扫描页表头一致时去重表头并合并 `<tbody>`；简单表支持按表头名称处理跨页列插入/删除/换序；
  带多级/合并表头的表格会展开表头为叶列键，在数据行无合并单元格时同样支持列变化合并；
  已验证真实 tesseract 的 `scan-table.pdf`、`scan-table-caption.pdf`、
  `scan-table-multi-header.pdf`、`scan-table-rowspan.pdf`、两列 `scan-table-two-column.pdf`
  与跨页 `scan-table-cross-page.pdf`、换列 `scan-table-column-change.pdf` 单测；
- **低对比度扫描预处理**：OCR 前灰度化、对比度拉伸、小图 2x 放大（`knowledge.ocr.preprocess` 默认 true）；
  已验证浅灰文字表格单测；不替代倾斜校正/专业去噪；
- **强噪点预处理**：检测椒盐噪声占比，超过阈值时自适应 3x3/5x5 中值滤波
  （`knowledge.ocr.denoise` 默认 true）；已验证 0.2% 噪点表格单测；
- **扫描页方向纠正**：tesseract OSD 检测 90/180/270 旋转并在 OCR 前转回正向
  （`knowledge.ocr.auto-orient` 默认 true）；已验证旋转 90° 的表格 PDF 单测；
- **小角度倾斜校正**：灰度投影方差在 -8°～8° 内寻找最佳角度（`knowledge.ocr.deskew` 默认 true）；
  已验证 6° 倾斜表格单测；强噪点/透视变形仍不保证；
- **PDF 表格标题/脚注**：表格上方 `Table/表/Figure/图` 行输出 `<caption>`；表格下方
  `Note/注/Source/来源/*` 行最多输出 3 条 `<p class="table-note">`；已验证多行脚注单测；
- **PDF 多级表头**：首个数值数据行之前的连续非数值行输出 `<thead>`/`<th>`；表头缺列时按列锚点
  推断 `colspan`；支持 2024/2025 年份型表头行；已验证两行和年份型表头单测；
- **PDF 纵向合并（保守）**：非数值列、最多合并 50 行；后续行该列为空且其他列有内容时推断
  `rowspan`；已验证首列、中间列、4 行与 12 行分组单测；
- **真实 qwen3-vl PDF 案例（2026-10-25，本机实测）**：
  - 上传 `complex-chart-photo.pdf`（页1：内嵌柱状图+风景照片；页2：矢量柱状图）→ 解析 DONE；

    - 照片/插图：识别渐变天空、太阳、山、水面和树木；
    - 矢量图表：识别标题 “Vector Sales Chart” 和 3 个递增蓝色柱；
  - 测试 KB 已删除，图片/分段随文档清理；
  - **注意**：模型可能误读图表数值（本案例 Q4 实际 390，模型描述为 300），图表数据点仍需结构化校验；
  - 复现：`VISION_TEST_ENABLED=true mvn -Dtest=PdfVisionCaseTest test`（默认跳过）；
- **PDF 多模态提示词**：区分图表（标题/坐标轴/图例/系列/数据点）、照片（场景/对象/可见文字）、
  扫描文档（标题/表格/关键字段）；
- **图表结构化 JSON（best-effort）**：图表描述命中后，视觉模型再输出
  `{isChart,title,xAxis,yAxis,series[points]}`；入库标记“模型识别，需人工核对”；
  真实 qwen3-vl 已验证标题提取，数据点可能为空/误读；输出 `reviewRequired=true`，
  有非空数据点标 `confidence=medium`，否则 `low`；不作为精确数据源；
- **图表数据人工复核**：图表分段在分段预览中显示“需核对/已核对”，编辑者可标记已核对或撤销；
  状态持久化到 `knowledge_chunk.review_status/reviewed_at/reviewed_by`，并记录审计日志；
  仅以 `【图表数据...】` 开头的图表分段可操作；
- **图表内容人工修正**：编辑图表数据正文后保存，会更新 `knowledge_chunk.content`、重新生成 embedding
  并同步 PgVector 内容/向量，同时自动标记已核对；保留 `【图表数据】` 标记，最多 4000 字；
  向量更新失败会明确提示重新解析；新增 JSON 结构/数值格式校验（series/data/points 类型、
  数值字段格式）；并将模型数值与文档文本数字归一化交叉比对；文档文本证据不足且启用 OCR 时，
  补充图表图片 OCR 数字作为证据；标记 `validationStatus=verified/conflict/unverified`，
  冲突时仍保留内容、降低置信度并要求人工核对；证据缺失时标 `unverified`，
  不能等同于数值真实性已证明；
- **向量业务有效期与时间过滤**：文档支持 `effective_from`/`effective_to`（上传区域/URL 导入直接选择，

  未配置时回退 `knowledge_document.created_at`；向量表同时保留技术时间 `created_at`/`updated_at`
  和业务有效期 `effective_from`/`effective_to`，并写入 metadata；
  旧表自动补列/回填，建立有效期索引；历史向量没有业务时间时先回填为原向量写入时间，
  可通过“重建有效期”按文档有效期/入库时间重刷；
  检索支持 `effectiveAfter`/`effectiveBefore`，向量、关键字和混合检索都在 SQL 的 `LIMIT` 前
  按有效期区间重叠过滤；时间筛选下跳过无有效期约束的图谱扩展；已验证 SQL 条件、参数校验、无效时间范围、
  上传/URL 导入有效期持久化、无有效期回退文档时间和旧表升级单测；

## 仍未完成

- 复杂 PPTX 合并单元格的边界情况（嵌套/不规则合并）仍需更多真实样本；
- PDF 矢量图表的数据序列还原（当前渲染页面后交给 OCR/多模态描述，不能保证还原每个数据点）；
- PDF 图表数值/系列的高可信结构化还原（真实 qwen3-vl 已能描述趋势，但可能误读数据点）；
  已提供人工修正内容并重新入库，且有 JSON 结构/数值格式校验及文档文本/OCR 交叉比对；
  仍缺少与原始图表逐点的可靠事实校验；
- PDF 文本层复杂表格：跨网格合并、重复表头名称/无共同表头的跨页表尚未完整支持；
  非数值列 rowspan（≤10 行）、简单两级表头、跨页续表（含列位置平移）、标题/脚注已支持；
- 扫描版 PDF 数据区带合并单元格的列变化仍未支持；带合并表头、简单数据行的列变化已支持；
  扫描图像长虚线可回退识别，
  扫描图像点线/大间隙严重断裂网格、透视变形、手写表格尚未验证；
- 加密 PDF 密码可在文档列表更新并重解析；密码长度最多 256 字符，未做失败次数限制；
- 文档列表可编辑有效期，并显示“当前有效/未生效/已过期”状态，可只看当前有效文档；
  上传和 URL 导入均可选择本次导入的有效期；
- 旧向量行首次升级时只能回填历史向量写入时间；可在文档列表点击“重建有效期”，按文档当前有效期/入库时间重刷全部向量；
- 时间筛选按有效期区间重叠过滤，向量/关键字/混合模式均生效；时间筛选下暂不追加图谱扩展分段；
  单点 as-of 可通过相同的 effectiveAfter/effectiveBefore 调用；
- 动态/渲染型 XFA 会提取 XML 数据路径和 template 字段/标签，不还原 Adobe 运行时布局、脚本增删行或可视化表单；
- 复杂不规则嵌套表头（超过 3 行、表头内数据/空单元格混杂）尚未完整验证；
- 两列扫描表格已支持（≥4 行），更少行数的两列表格不结构化；
- embedding 已分批；大文档/大表格真实性能与内存压测尚未执行。
