  旧表自动补列/回填，建立有效期索引；历史向量没有业务时间时先回填为原向量写入时间，

  按有效期区间重叠过滤；时间筛选下跳过无有效期约束的图谱扩展；已验证 SQL 条件、参数校验、无效时间范围、

## 仍未完成

- PDF 矢量图表的数据序列还原（当前渲染页面后交给 OCR/多模态描述，不能保证还原每个数据点）；
- PDF 图表数值/系列的高可信结构化还原（真实 qwen3-vl 已能描述趋势，但可能误读数据点）；
  已提供人工修正内容并重新入库，且有 JSON 结构/数值格式校验及文档文本/OCR 交叉比对；
  仍缺少与原始图表逐点的可靠事实校验；
- PDF 文本层复杂表格：跨网格合并、重复表头名称/无共同表头的跨页表尚未完整支持；

- 扫描版 PDF 带合并表头、数据区 colspan/rowspan 的跨页列变化已支持；
  扫描图像长虚线/点线可回退识别；大间隙严重断裂网格、透视变形、手写表格尚未验证；
