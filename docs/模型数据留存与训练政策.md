# 模型数据留存与训练政策

更新日期：2026-11-03

本说明用于向租户披露平台在调用模型时如何处理数据。租户可在登录页和 Agent 模型选择处打开 `/data-policy` 查看同一份说明。

## 1. 平台自身

- 平台不会使用租户的对话、知识库文档、附件或评测数据训练平台自有模型。
- 平台数据按租户隔离存储；租户数据库、向量库和对象存储的访问由平台权限控制。
- 备份文件按部署配置加密保存；备份保留周期由部署管理员配置。

## 2. 模型调用与外部供应商

使用对话、知识库检索、图片识别、语音转写或评测时，必要的提示词、检索片段、附件内容和上下文会发送给租户选择的模型服务：

- **本地 Ollama**：数据留在部署环境内，不离开平台部署边界。
- **外部 Provider（DeepSeek 或其他 OpenAI 兼容服务）**：数据发送给该供应商。供应商的留存期限、是否用于训练、数据出境、删除机制和审计能力由其服务条款与隐私政策决定。
- 平台不能在供应商条款之外替供应商作出“不留存/不训练”的承诺。对数据训练或出境有严格要求的租户应选择本地模型，或由管理员先完成供应商条款评估。

### 2.1 按供应商列出的状态

| 供应商/类型 | 用于训练 | 留存 | 数据出境 | 当前确认状态 |
|---|---|---|---|---|
| 本地 Ollama | 否（平台不使用租户数据训练） | 部署配置的本地卷/日志 | 否，不离开部署环境 | 部署方责任 |
| DeepSeek | 未确认，以供应商条款为准 | 未确认，以供应商条款为准 | 需按供应商条款和部署地区判断 | **法务/供应商条款待确认** |
| OpenAI | 未确认，以供应商条款为准 | 未确认，以供应商条款为准 | 需按供应商条款和部署地区判断 | **法务/供应商条款待确认** |
| Anthropic | 未确认，以供应商条款为准 | 未确认，以供应商条款为准 | 需按供应商条款和部署地区判断 | **法务/供应商条款待确认** |
| 自建 OpenAI-compatible | 由租户/部署方控制 | 由部署方控制 | 由部署方网络边界决定 | 租户/部署方责任 |

> “未确认”不等于“不会训练”或“不会出境”。上线前必须由法务/安全负责人逐家确认，不能把待确认项改写成供应商承诺。

## 3. 留存与删除

- 消息默认采用 90 天归档策略；审计记录默认保留 180 天；系统日志默认保留 7 天。
- Trace、附件、知识库文档和备份的实际保留时间以部署配置、租户配置和备份保留周期为准。
- 租户可删除会话、知识库文档和附件，或联系平台管理员申请清理；备份中的历史副本会按备份保留周期自然过期。

## 4. 租户控制

- 租户可在 Provider 配置中选择本地模型或外部模型。
- 租户可在知识库和 Agent 配置中限制检索范围，并通过成员权限控制访问。
- 上线前应将本说明与供应商实际条款、隐私政策和用户协议一并提供给租户确认。

## 5. 说明

本页是平台透明说明，不替代与租户签署的合同、隐私政策、用户协议或模型供应商条款。具体供应商、留存周期、训练状态和跨境安排以管理员配置及供应商最新条款为准。
