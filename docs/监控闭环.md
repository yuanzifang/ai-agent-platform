# 监控闭环

## 链路

```text
Backend/Agent
  ├─ /actuator/prometheus ──> Prometheus ──> Alertmanager
  │                                      └─> alert-relay ──> 钉钉/邮件
  ├─ 容器日志 / logs/backend.log ──> Promtail ──> Loki
  └─ OTLP Traces ──> OTel Collector ──> Tempo

MySQL / Redis / PostgreSQL
  └─ exporter ──> Prometheus

Grafana
  ├─ Prometheus：Overview / Database
  ├─ Loki：Logs
  └─ Tempo：Trace 查询
```

## 本地组件

| 组件 | 端口 | 说明 |
|---|---|---|
| Prometheus | `9090` | 指标、规则、告警 |
| Alertmanager | `19093` | 本地路由到 relay |
| alert-relay | `18099` | 钉钉/邮件投递、ACK/升级 |
| Loki | `3100` | 日志存储 |
| Promtail | `9080` | Docker 容器 + 原生 backend 文件日志 |
| Tempo | `3200` | Trace 存储 |
| OTel Collector | `4317/4318` | OTLP 接收 |
| Grafana | `3000` | 看板/Explore |

本地 native backend 日志写入 `logs/backend.log`，由 `deploy/observability/promtail.native.yml` 采集。
Compose 部署使用 `deploy/observability/promtail.yml`，直接采集 Docker 容器日志。

## 验证过的链路

- OTLP smoke trace：Collector `/v1/traces` 返回 200，Tempo `/api/traces/{id}` 返回 trace
- Loki：`{job="native-backend"}` 能查到 backend 日志
- Prometheus：backend、MySQL、Redis、PostgreSQL targets 均为 `up`
- Alertmanager：演练 warning 告警接收成功，webhook 通知尝试成功，告警到期后自动 resolved
- Grafana：Overview、Logs、Database 看板已加载

## 对象存储

本地已用 MinIO 验证 Loki/Tempo S3：

- Loki chunk：`loki-chunks`
- Tempo block：`tempo-traces`
- 本地当前 Loki/Tempo 已切换到 S3 配置
- 配置模板：`deploy/observability/loki.s3.example.yml`、`tempo.s3.example.yml`
- 真实凭据只放本机 `runtime/observability/*.s3.yml` 或部署 Secret，不提交
