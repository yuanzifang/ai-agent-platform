# 飞书文档导入知识库

知识库详情页新增「飞书导入」，支持：

```text
https://xxx.feishu.cn/docx/<token>
https://xxx.feishu.cn/docs/<token>
https://xxx.feishu.cn/wiki/<node_token>
https://xxx.feishu.cn/wiki/space/<space_id>
https://xxx.feishu.cn/drive/folder/<folder_token>
https://xxx.feishu.cn/sheets/<spreadsheet_token>
https://xxx.feishu.cn/base/<app_token>
```

## 流程

1. 前端输入飞书 URL、App ID、App Secret（仅本次请求使用，不落库）；
2. 后端用 App ID/Secret 换取 `tenant_access_token`；
3. docx 优先读取 blocks 并转成 Markdown，保留标题、列表、引用、表格和超链接；blocks 读取失败时回退 raw_content；同时从 blocks 提取飞书文档超链接、file 附件、图片 OCR 和内嵌 bitable/sheet，并追加 docx 评论/回复；链接文档/附件/内嵌表格各自作为独立文档继续导入；wiki 节点或空间递归读取节点树；drive folder 递归读取文件夹，多维表格转成文本记录，电子表格按工作表读取单元格；文件夹/知识库树和正文超链接均最多三层；
4. 文档文本/云盘文件写入 MinIO；
5. 复用知识库现有解析、分块、embedding 和向量写入链路；长文按父块约 2000 字符、子块约 500 字符（50 字重叠）切分，表格和代码块保持原子性；
6. 返回成功/失败/跳过数量，前端刷新文档列表；
7. 大文件夹可使用异步任务接口，提交后立即返回 `jobId`，前端轮询进度。

## 飞书应用权限

按实际要导入的类型开通只读权限，常见包括：

- 新版云文档：`docx:document:readonly`
- 旧版文档：`docs:doc:readonly`（或 `drive:drive:readonly`）
- 知识库：`wiki:wiki:readonly`
- 云盘文件：`drive:drive:readonly`
- 多维表格：`bitable:app:readonly`
- 电子表格：`sheets:spreadsheet:readonly`
- 文档评论：`docs:document.comment:read`（可选，读取失败不影响正文）
- 目录列表/文件下载需要 drive 相关只读权限

应用需要发布并经管理员审核，且测试用户在应用可用范围内。权限不足时接口会返回飞书 API 错误信息。

### 文件夹权限

飞书不支持把应用直接添加为文件夹协作者。需要：

1. 应用添加「机器人」能力并发布；
2. 在飞书创建群组，把应用添加为群机器人；
3. 把目标文件夹分享给该群组，并授予可阅读/可管理权限。

否则文件夹元数据和文件清单接口会返回 `1061004 forbidden`。

## 限制

- 单次默认最多 100 个文件（`FEISHU_MAX_FILES` 可调）；
- 单次默认总内容不超过 50MB（`FEISHU_MAX_BYTES` 可调）；
- 文件夹/wiki 树最多三层：根层为 1，子层为 2，孙层为 3；更深节点跳过并在响应 `skippedItems` 中返回；
- 单个文档/子文件夹无权限或读取失败不会中断整批导入，会记录到 `skippedItems` 后继续；
- 长文自动按父子块切分，不按飞书原始文档长度硬截断；
- 正文中指向飞书 `/docx/`、`/docs/`、`/wiki/` 的超链接和 `@文档` mention 会作为独立文档导入；外部链接和非文档链接跳过；
- `docx` 优先 blocks → Markdown，保留标题层级、列表、引用、表格和超链接；docx 内 file 附件下载为独立文档；内嵌 bitable/sheet 转为独立文档；图片会下载并做本地 OCR，文字追加到主文档；设置 `FEISHU_IMAGE_VISION_ENABLED=true` 后会额外调用本地视觉模型生成照片/图表语义；blocks 不可用时回退 raw_content 纯文本；
- 文件夹中的 `docx`、`doc`、`folder`、`file`、`bitable`、`sheet` 支持；bitable 每张表转为文本记录并独立入库，sheet 每个工作表转为文本并独立入库；
- 图片视觉模型默认关闭（`FEISHU_IMAGE_VISION_ENABLED=false`），避免批量导入被大视觉模型拖慢；启用时可配置 `FEISHU_IMAGE_VISION_MODEL`（默认 `qwen3-vl:32b`）；
- docx 评论默认读取并追加到主文档（`FEISHU_INCLUDE_COMMENTS=true`），评论回复超过一页会自动翻页；评论读取失败只跳过评论；
- `reference_synced` 引用同步块会展开源文档内容；无源文档权限时保留占位符；
- `iframe` / `link_preview` 会保留可读 URL，URL 编码会自动解码；
- App Secret 不写入数据库、日志或仓库；
- 异步任务视图写入 Redis（2 小时 TTL），多副本可共享进度查询；任务执行仍绑定提交实例，实例宕机不会自动迁移，生产高可用需要补任务队列/重试。

## 飞书2md 备用方案

单机批量导入也可以使用 `feishu2md`：

```bash
./feishu2md config --appId <app_id> --appSecret <app_secret>
./feishu2md dl "https://xxx.feishu.cn/docx/<token>"
./feishu2md dl --wiki "https://xxx.feishu.cn/wiki/<node_token>"
```

下载得到的 Markdown 可以通过知识库普通上传入口导入。平台内置入口不依赖本地二进制，适合 UI/多人使用。
