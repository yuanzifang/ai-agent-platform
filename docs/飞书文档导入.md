# 飞书文档导入知识库

知识库详情页新增「飞书导入」，支持：

```text
https://xxx.feishu.cn/docx/<token>
https://xxx.feishu.cn/docs/<token>
https://xxx.feishu.cn/wiki/<node_token>
https://xxx.feishu.cn/wiki/space/<space_id>
https://xxx.feishu.cn/drive/folder/<folder_token>
```

## 流程

1. 前端输入飞书 URL、App ID、App Secret（仅本次请求使用，不落库）；
2. 后端用 App ID/Secret 换取 `tenant_access_token`；
3. docx 读取 raw_content 纯文本；wiki 节点或空间递归读取节点树；drive folder 递归读取文件夹；
4. 文档文本/云盘文件写入 MinIO；
5. 复用知识库现有解析、分块、embedding 和向量写入链路；
6. 返回成功/失败数量，前端刷新文档列表。

## 飞书应用权限

按实际要导入的类型开通只读权限，常见包括：

- 新版云文档：`docx:document:readonly`
- 旧版文档：`docs:doc:readonly`（或 `drive:drive:readonly`）
- 知识库：`wiki:wiki:readonly`
- 云盘文件：`drive:drive:readonly`
- 目录列表/文件下载需要 drive 相关只读权限

应用需要发布并经管理员审核，且测试用户在应用可用范围内。权限不足时接口会返回飞书 API 错误信息。

## 限制

- 单次最多 100 个文件；
- 单次总内容不超过 50MB；
- `docx` 使用 raw_content 纯文本，标题层级、表格、图片和附件不会保留；需要完整 Markdown/图片时使用下方 `feishu2md` 备用方案；
- 文件夹中的 `docx`、`doc`、`folder`、`file` 支持；sheet/bitable 暂不导入；
- App Secret 不写入数据库、日志或仓库。

## 飞书2md 备用方案

单机批量导入也可以使用 `feishu2md`：

```bash
./feishu2md config --appId <app_id> --appSecret <app_secret>
./feishu2md dl "https://xxx.feishu.cn/docx/<token>"
./feishu2md dl --wiki "https://xxx.feishu.cn/wiki/<node_token>"
```

下载得到的 Markdown 可以通过知识库普通上传入口导入。平台内置入口不依赖本地二进制，适合 UI/多人使用。
