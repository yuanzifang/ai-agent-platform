# 渠道接入

## 已支持

- 入站文本：Webhook / Slack / 钉钉 / 飞书 / 企微；
- 出站文本：通用 Webhook / Slack / 钉钉 / 飞书 / 企微；
- 公开入站 token 鉴权、渠道限流、事件去重、消息留痕；
- 安全：出站 URL 走 NetworkPolicy SSRF 校验；
- **媒体 URL 兜底**：纯媒体消息若没有文本，但 payload 含 `image_url/pic_url/media_url/file_url/url`，以
  `[媒体消息] URL` 进入对话并留痕；不下载/理解媒体；
- **出站重试**：每轮 2 次，间隔 250ms/500ms；
- **最终失败通知**：写入渠道创建人站内通知 `channel_error`，消息记录状态 ERROR；
- 出站响应非 2xx 视为失败。

## 未完成

## 已验证

- E2E：
  - 文本入站 → Agent 回复 → 出站捕获；
  - 媒体 URL 入站兜底；
  - 出站第一次 500、第二次 200，`outboundSent=true`；
  - 完整 E2E 46/46。
