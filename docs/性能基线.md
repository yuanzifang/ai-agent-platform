# 本机 API 性能基线

日期：2026-10-24  
环境：本机 macOS、后端单实例、MySQL/Redis 本机、数据量为开发基线（3 Agent、13 会话、96 消息）。  
工具：ApacheBench（`ab`），200 请求、20 并发、GET、租户限流临时放开。  
结论：**这是基线观测，不是上线压测验收**；未覆盖首 Token、RAG 检索、审核、SSE 并发。
