# 技能脚本沙箱

## 运行时

```yaml
skill:
  script:
    runtime: docker          # process / docker
    require-image-digest: true
    docker:
      python-image: python:3.12-alpine@sha256:<digest>
      node-image: node:22-alpine@sha256:<digest>
```

- `process`：本机开发用，进程级隔离。
- `docker`：容器级隔离，`--network none`、内存/CPU/PID 限额、`cap-drop ALL`、`no-new-privileges`、`noexec tmpfs`。
- `require-image-digest=true` 时镜像必须带 `@sha256:<64 hex>`，否则脚本执行直接失败，避免 tag 漂移。
- 当前默认 `false`，生产/SaaS 应开启并固定 digest。

## 执行审计

每次脚本执行输出结构化日志：

```text
SKILL_EXEC tenant=... lang=PYTHON runtime=docker codeHash=<16hex> durationMs=... exit=0 truncated=false
```

日志不含脚本正文/参数，只保留租户、语言、隔离层、代码哈希、耗时、退出码和截断标记，便于审计和性能排查。

## 验证

- `ScriptRunnerDockerCommandTest` 覆盖 digest 校验与 Docker 命令硬约束。
- Docker 实测 IT 覆盖容器执行、参数注入、禁网。
