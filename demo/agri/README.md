## 内容

1. 开场：农业知识问答助手，157 篇农技资料、RAG、图片/语音入口
2. 图片提问：上传叶片照片，问“这个叶子是什么病？怎么防治？”
3. 文本提问：番茄灰霉病怎么防治？
4. 安全兜底：输入“随便推荐一个农药就行”，展示拒答和补充信息要求
5. 收尾：AI 只做辅助查询，不替代当地农技/植保部门

## 发布文案建议

### 小红书

标题：

> 给农户做了个 AI 农技助手，拍张叶子就能问病害

正文：

> 把 157 篇农业农村部、全国农技中心的资料放进知识库，  
> 支持文字、图片、语音提问，回答会带资料引用。  
> 试了一下番茄灰霉病和“随便推荐农药”，它能给出防治思路，也会拒绝没有依据的荐药。  
> 目前是 POC 演示，具体诊断和用药请以当地农技/植保部门为准。

### B站

标题：

> 用 157 篇农技资料搭一个农业 RAG Agent：图片识别 + 语音提问 + 安全兜底

简介：

> 农业知识问答助手 POC：混合检索、父子分块、图片识别、语音转写、安全兜底。  
> 当前完整 60 题通过率约 73%，仍有跨作物、知识覆盖和长回答问题，仅作辅助查询演示。

## 录制注意事项

- 不展示 Widget Key、内部 Token、后台配置和私有文档 URL
- 用固定测试账号/干净会话
- 提前预热模型，避免首个问题等待过长
- 视频中的回答仅代表 POC，不承诺产量、治愈率或具体农药剂量
- 发布时保留“请咨询当地农技/植保部门”的提示
