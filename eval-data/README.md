# Evaluation data

Generated evaluation outputs and benchmark datasets live here, not under `docs/`.

- `agri/`: agricultural answer-quality baselines, failure reruns, model comparisons,
  and the 60-question evaluation set.
- These files are inputs/outputs for `scripts/eval-agri-answer-quality.py`,
  `scripts/rescore-agri-quality.py`, and `scripts/compare-agri-models.py`.
- Documentation should link to this directory instead of copying generated JSON
  into `docs/`.

Generated artifacts are retained for reproducibility; do not treat them as
hand-maintained documentation.
